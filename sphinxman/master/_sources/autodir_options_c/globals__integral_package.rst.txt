:term:`INTEGRAL_PACKAGE <INTEGRAL_PACKAGE (GLOBALS)>`
"""""""""""""""""""""""""""""""""""""""""""""""""""""

      Integral package to use for two-electron integrals. LIBINT2 computes them all. SIMINT computes the non-derivative Coulomb integrals, and Libint2 the derivative, range-separated, and other integrals. LIBCINT (experimental) computes the Coulomb and range-separated erf/erfc integrals, 4-center and density-fitted, with first and second derivatives, and Libint2 the others (e.g., Yukawa and F12). Each package's angular momentum limit applies. Requesting SIMINT or LIBCINT when it is not compiled in is an error.

      * **Type**: string
      * **Possible Values**: LIBINT2, SIMINT, LIBCINT
      * **Default**: LIBINT2
