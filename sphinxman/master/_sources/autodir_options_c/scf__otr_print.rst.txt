:term:`OTR_PRINT <OTR_PRINT (SCF)>`
"""""""""""""""""""""""""""""""""""

      For :term:`SECOND_ORDER_ORBITAL_OPTIMIZER_PACKAGE <SECOND_ORDER_ORBITAL_OPTIMIZER_PACKAGE (GLOBALS)>` = `OTR`, verbosity of the solver's own printing: 0 only warnings and errors, 1 its macro-iteration table, 2 or more adds debug messages (only for :term:`OTR_SUBSYSTEM_SOLVER <OTR_SUBSYSTEM_SOLVER (SCF)>` = `TCG`). The table follows the SCF iteration rows, which report the same macro iterations in Psi4's format. Unset, this follows :term:`SOSCF_PRINT <SOSCF_PRINT (SCF)>` ; setting it overrides that.

      * **Type**: integer
      * **Default**: 1
